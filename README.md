# Sliding Puzzle Game

A desktop sliding puzzle game built with Java and JavaFX.

## Features
- Two difficulty levels (3x3 and 4x4)
- Move counter and timer
- Best score saved to a file
- MVC architecture applying OOP principles (interface, enum, singleton)

## Technologies
Java, JavaFX

## How to Run
1. Open the project in Eclipse or IntelliJ with JavaFX configured
2. Run `src/PuzzelGame/Main.java`
